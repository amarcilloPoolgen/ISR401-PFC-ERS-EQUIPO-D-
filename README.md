# 🐾 SGCV-IA
## Sistema de Gestión para Clínicas Veterinarias con Inteligencia Artificial

Repositorio de la Práctica Experimental – Unidad IV
Ingeniería de Requisitos (ISR-401)

---

## 📖 Descripción

SGCV-IA es un Sistema de Gestión para Clínicas Veterinarias con Inteligencia Artificial diseñado para apoyar la administración de clínicas veterinarias mediante la gestión de historiales clínicos, inventario, citas, facturación, reportes y herramientas de Inteligencia Artificial para asistencia diagnóstica y seguimiento nutricional. El proyecto fue desarrollado siguiendo el estándar IEEE/ISO/IEC 29148:2018.

## 🎯 Objetivo

Desarrollar y documentar la Especificación de Requisitos de Software (ERS) del sistema SGCV-IA aplicando técnicas de Ingeniería de Requisitos, incluyendo elicitación, modelado UML, priorización MoSCoW, trazabilidad, control de cambios y gestión de versiones.

---

## 🚀 Funcionalidades principales

- Gestión de historiales clínicos.
- Gestión de citas.
- Control de inventario.
- Facturación.
- Asistente de diagnóstico mediante IA.
- Seguimiento nutricional.
- Generación de reportes.
- Gestión de usuarios y permisos.

## 📂 Descripción de carpetas

- **01_ERS:** Documento de Especificación de Requisitos de Software.
- **02_Inspeccion:** Evidencias de inspección Fagan.
- **03_CCB:** Solicitudes de Cambio (RFC) y documentación del CCB.
- **04_Trazabilidad:** Matriz de trazabilidad.
- **05_Informe:** Informe de la práctica.
- **06_Evidencias:** Capturas de Git, GitHub, Jira y demás evidencias.

## ⚙️ Uso del repositorio

Este repositorio contiene únicamente documentación del proyecto.
